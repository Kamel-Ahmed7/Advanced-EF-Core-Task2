Advanced Entity Framework Core (Task 2)

استعلامات LINQ المتقدمة، التحميل المباشر (Eager Loading)، وتتبع الأداء

1. Eager Loading (التحميل المبكر باستخدام Include و ThenInclude)

تستخدم لجلب البيانات المرتبطة (Related Data) مع الجدول الرئيسي في نفس استعلام قاعدة البيانات لتجنب مشاكل الأداء.

var orders = _context.Customers
    .Where(c => c.Country == "Egypt")
    .Include(c => c.Orders)
        .ThenInclude(o => o.OrderItems)
            .ThenInclude(oi => oi.Product)
    .ToList();
SELECT c.*, o.*, oi.*, p.* FROM Customers c LEFT JOIN Orders o ON c.Id = o.CustomerId LEFT JOIN OrderItems oi ON o.Id = oi.OrderId LEFT JOIN Products p ON oi.ProductId = p.Id WHERE c.Country = 'Egypt'

2. Advanced LINQ Projections (اخراج بيانات مخصصة)

بدلاً من جلب الجدول كاملاً، يتم جلب الأعمدة المطلوبة فقط في شكل DTO لتحسين الأداء وسرعة الاستجابة.

var result = _context.Employees
    .Where(e => e.Salary > 10000)
    .Select(e => new EmployeeDto {
        FullName = e.FirstName + " " + e.LastName,
        DepartmentName = e.Department.Name,
        AnnualSalary = e.Salary * 12
    })
    .ToList();
